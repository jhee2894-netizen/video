# 🎬 Remotion Shorts & Reels 프로젝트

이 저장소는 **Remotion (React 기반 프로그래밍 방식 비디오 제작 프레임워크)**을 활용하여 제작된 인스타그램 릴스 및 유튜브 숏츠 영상 프로젝트입니다.

---

## 📽️ 제작된 영상 목록

### 1. 🐱 아저씨 고양이 패러디 릴스 (`RealReel`)
- **결과 파일**: [`out/real.mp4`](out/real.mp4)
- **규격**: 1080 × 1920 (9:16 세로형 숏폼), 30fps, 19초
- **컨셉**: 영화 *'아저씨'*의 명대사를 고양이의 시선과 행동에 완벽 매칭한 시네마틱 숏츠
- **주요 연출 및 수정 내역**:
  - 클링(Kling AI) 워터마크 완벽 크롭 및 1080×860 숏폼 비율 최적화
  - **Shot 1 (창가 원경, 0초 ~ 5.67초)**: 창밖을 응시하는 원경 샷 (긴장감 조성)
  - **Shot 2 (눈빛 클로즈업 대폭 연장, 5.67초 ~ 14.67초, 9초간)**:
    - 5~6초 구간 컷 튐 없이 매끄러운 클로즈업 전환
    - 영화 원본 호흡에 맞춰 클로즈업 구간을 연장하여 '죽는다'까지 완벽 수용
  - **Shot 3 (걸어 나오는 씬, 14.67초 ~ 19.0초)**: 결의에 차 걸어 나오는 씬
  - **영화 '아저씨' 원빈 배우 100% 실제 육성 정밀 싱크 & 부드러운 오디오 트랜지션**:
    - **연속 배경음악 (BGM)**: 영화 오리지널 첼로 누아르 스코어 & 빗소리 트랙(`noir_bgm.mp3`)을 22초간 무단절 크로스페이드 루프로 리마스터링하여 영상 전체(0~19초)에 끊김 및 튀는 팝 노이즈 없이 매끄럽게 연결
    - **부드러운 볼륨 엔벨로프**: 음성 클립 앞뒤 30ms 페이드 및 자연스러운 믹싱으로 뚝뚝 끊기는 현상 완전 해소
    - **3.0초 (90f ~ 145f)**: *"니들은 내일만 보고 살지?"* (대사 초반의 "그게.." 타인 음성 완전 제거, 즉각적이고 명확한 원빈 육성 진입)
    - **4.93초 (148f ~ 348f)**: *"내일만 사는 놈은 오늘만 사는 놈한테 죽는다"* ('죽는다'의 '다'까지 100% 잘림 없이 완벽히 끝까지 송출)
    - **11.60초 ~ 12.60초 (348f ~ 378f)**: 대사 간 정확히 **1.0초간의 긴장감 넘치는 정적 및 BGM 호흡 간격** 부여
    - **12.60초 (378f ~ 415f)**: *"난 오늘만 산다"* (14초 이전인 13.83초에 음성/자막 완벽 종료, 옐로우 강조)
    - **13.83초 ~ 16.0초**: 끊기지 않는 묵직한 첼로 BGM과 함께 걸어 나오는 씬 진입 (압도적 긴장감 고조)
    - **16.0초 (480f ~ 555f)**: *"내가 보여줄게"* (16초 정각 시작, 걸어 나오는 샷에서 진짜 원빈 육성 100% 매칭, 오렌지레드 강조)
  - **폰트**: Pretendard ExtraBold

### 2. 📊 개념 설명 릴스 (`ConceptReel`)
- **결과 파일**: [`out/concept.mp4`](out/concept.mp4)
- **규격**: 1080 × 1920 (9:16 세로형 숏폼), 30fps, 10초 무한 루프
- **컨셉**: 6단계 파이프라인 개념을 순차적으로 시각화하는 인포그래픽 릴스
- **인스타그램 안전 구역 준수**: 상단 210px, 하단 320px, 우측 84px 여백 확보

## 🚀 실행 및 렌더링 방법

### 1. 의존성 설치
```bash
npm install
```

### 2. Remotion 미리보기 (Preview Player)
```bash
npx remotion preview
```

### 3. 영상 렌더링
```bash
# 아저씨 패러디 고양이 숏츠
npx remotion render src/index.ts RealReel out/real.mp4

# 개념 릴스
npx remotion render src/index.ts ConceptReel out/concept.mp4
```
